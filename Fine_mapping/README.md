# Fine-mapping

### Prerequisite:  
- To run fine-mapping using SuSiE, we first downloaded the pre-computed LD matrices of UKB EUR here: https://uchicago.app.box.com/s/jqocacd2fulskmhoqnasrknbt59x3xkn

- `1.run_susie.R`: Script that processes GWAS summary statistics for selected traits and then runs SuSiE.
- `2.post_processing.R`: Script that extracts likely causal SNPs and processes data for running PRS-CS.
