# PGS-Catalog

### Scripts here were applied to UKBB imputation data. The codes that applied to direct genotyping data are very similar:

- `1.harmonization.R`: Script that fixes allele mismatching between discovery and target data.
- `2.pgs.sh`: Script that runs PGS on the UKBB cohort based on pre-trained models from PGS-Catalog (scoring file).
- `3.r2.R`: Script that computes R^2 for PGS.
