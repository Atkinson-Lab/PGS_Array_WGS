# Simulation

### In addition to the original simulation code that ran on the controlled All of Us genotype data, we also provide a toy dataset generated from the public TGP-HGDP join callset. The code should be adaptable to run with the toy data. 

- `simulation_AoU_v7.ipynb`: Original code for running simulations on All of Us v7.
- `toy_dataset`: Contains PLINK pfiles for a subset of 691 European samples from TGP-HGDP, which can be used to quickly replicate our simulation pipeline.
